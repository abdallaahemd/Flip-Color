# Flip Color

A simple interactive page with a single button. Clicking **Flip Color** switches the page background between two colors.

![Flip Color screenshot](screenshots/flip-color.png)

## Features

- One-click background color toggle
- Simple, lightweight project, ideal for learning the basics of DOM events

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/abdallaahemd/Flip-Color.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
